# tax-analysis-skill

税务问题分析技能的发布仓库。技能本体位于 `skills/tax-analysis-skill/`（`gh skill` 要求的虚拟文件树结构），本地技能目录保持原有布局不变。

## 安装

```bash
gh skill install kuailexiaozixin/tax-analysis-skill
```

锁定版本：

```bash
gh skill install kuailexiaozixin/tax-analysis-skill tax-analysis-skill --pin v3.62.2
```

## 结构

- `skills/tax-analysis-skill/` — 技能本体：`SKILL.md`、`subskills/`（9 个子技能）、`scripts/`、`references/`、`tests/`
- `README.md`、`SKILL.md`（技能根） — 仓库与版本的说明入口见技能内文件
