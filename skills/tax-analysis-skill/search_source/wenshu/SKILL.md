# 中国裁判文书网（wenshu）——墙在接口层，且参数要前端现算

线上：https://wenshu.court.gov.cn/ （页面层匿名可达，接口层匿名一律不给数据）

本目录是**墙位档案**不是取数器：2026-11-25 首次实测（此前本机一次请求都没发过）。
与 `search_source/rmfyalk/` 同一族病、不同难度——案例库缺登录态，这一站缺的是
**前端算出来的检索参数**。

## 什么时候用 / 不用

**用**：用户点名要裁判文书网某一份判决书原文；或需要说明"这一层取不到、取不到的技术
原因是什么"。取证前先读 NOTE.md 第二节与第三节。

**不用**：人民法院案例库的入库案例（墙形不同，走 `search_source/rmfyalk/`）；
税务查处通报与曝光典型（`scripts/tax_cases.py` 已接入的层）。

## 工作流

1. **不发请求就能答的**：按现状答"裁判文书网未接入，本仓库的司法层是空的"，并说明
   原因写在 `search_source/wenshu/NOTE.md`——**不要**把它写成"网上查不到这份文书"。
2. **要复测墙形的**：手动跑本目录 `probe_wenshu_wall.py`（会发真请求，逐发间隔 2.6 秒），
   对照 NOTE.md 第二节读数；形状变了就更新 `references/source_defects.md` 的
   「仍然是边界的几件事」一节与本目录。
3. **判据**：这一族用 `tax_http.court_business_error`／`tax_http.require_court_ok`
   （成功值 `code=0`，且 `success` 为 `false` 先报失败）。实测匿名发 `rest.q4w`
   回 `{"code":9,…,"success":false}`，与不带参数完全同形——**这一句不是"0 条命中"**。

## 取到之后放哪（给母技能主线看）

现在取不到。将来接入时，判决书原文属司法裁判文本，不进母技能的税收效力位阶表打分；
引用必须带**案号 + 法院 + 裁判日期**三件，缺一件读者核不了。

## 两条硬规矩

- **`code=9` + `success:false` 是失败不是空结果**；三枚 `/api/fp/*` 接口回
  **200 / 0 字节**（空响应，连 JSON 都不是），同样不许读成"库里没有"。
- **不重造这套加密**。`strToBinary.js` 里 `cipher()`＝`salt + 当日 iv + DES3(timestamp)`，
  站点配置还带一枚 `enCode`；本仓库不实现它，也不拿"仿造参数试一发"去消耗额度。
