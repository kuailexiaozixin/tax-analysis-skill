## 〇、问答原文（逐字摘录，未经改写）

（四）样机从研发至对外销售或验收不通过各环节的会计处理，研发样机计入研发费用或产品成本的判断依据，会计处理是否符合《企业会计准则》和《监管规则适用指引——发行类第9号》规定；报告期各期形成的研发样机数量及金额、试用情况、销售情况、剩余样机去向，是否存在长期未结转收入或被退回的情形；研发样机的销售毛利率是否高于同类产品

1、样机从研发至对外销售或验收不通过各环节的会计处理，研发样机计入研发费用或产品成本的判断依据，会计处理是否符合《企业会计准则》和《监管规则适用指引——发行类第9号》规定

| 样机阶段 | 具体会计处理 |
|---|---|
| 研发样机签署销售合同前 | 相关支出计入研发费用 |
| 研发样机签署销售合同后 | 相关支出计入存货 |
| 研发样机对外销售取得验收 | 借：应收账款 |
|  | 贷：主营业务收入 |
|  | 贷：应交税费-应交增值税（销项税额） |
|  | 借：主营业务成本 |
|  | 贷：存货-发出商品 |

发行人参照《企业会计准则》、《监管规则适用指引——发行类第9号》及2025年4月17日财政部会计司发布的无形资产准则实施问答进行研发样机的会计处理。

根据《监管规则适用指引——发行类第9号》，“发行人在研发过程中产出的产品或副产品，符合《企业会计准则第1号——存货》规定的应当确认为存货，符合其他相关企业会计准则中有关资产确认条件的应当确认为相关资产。发行人应准确归集核算有关产品或副产品的成本，并在对外销售时，按照《企业会计准则第14号——收入》《企业会计准则第1号——存货》《企业会计准则解释第15号》等规定，对销售相关的收入和成本分别进行会计处理。原则上研发过程中产出的产品或副产品，其成本不得计入研发投入。”

根据2025年4月17日财政部会计司发布的无形资产准则实施问答，“公司已经按照无形资产准则、《企业会计准则解释第15号》等规定，判断当期研发支出不满足无形资产、存货等资产的确认条件，将研发支出（包括研发样机的相关支出）全部作费用化处理，并计入了当期研发费用，不应在以后期间签订销售合同或者销售研发样机时，将以前期间已费用化的研发样机支出金额从本期研发费用中冲回后再转入存货或营业成本等。”

根据上述规定，发行人研发样机计入研发费用或产品成本的判断依据为样机销售合同是否签订，样机销售合同签订前发生的支出进入研发费用，合同签订后发生的支出进入存货。

综上，研发样机相关会计处理符合《企业会计准则》和《监管规则适用指引——发行类第9号》规定。

2023年公司销售的贴片设备类研发样机、2024年公司销售的其他设备类研发样机毛利率分别为40.82%、31.36%，低于当年该类型设备毛利率，主要系研发样机发生的相关物料及人工等支出金额较高所致。

二、中介机构核查情况

（一）核查程序

针对上述事项，保荐人及申报会计师履行了以下核查程序：

1、获取报告期内员工花名册、员工考勤表、工资表等，了解员工人数变化、薪酬等级分布及构成情况；

2、查阅统计局公布的城镇私营单位就业人员平均工资数据，计算公司报告期各期销售人员和管理人员平均薪酬情况，与当地平均薪酬水平进行比对，并分析差异原因；查阅同行业可比公司定期报告，与同行业可比公司薪酬水平进行比对，并分析差异原因；

3、获取公司研发费用明细表，分析报告期内主要研发项目，了解相关研发项目的基本情况、进展等，分析公司研发人员数量、研发费用金额增长较快的合理性；

4、了解公司研发人员的主要工作职能，核查公司报告期内兼职研发人员转为全职研发人员的名单、背景、工作内容，分析兼职研发人员转为全职研发人员的合理性；

5、获取公司研发样机明细表，分析各期研发样机的变动情况、销售情况，核查公司研发样机的业务背景、流程及相应会计处理，分析是否符合会计准则相关规定，核查研发样机是否存在长期未结转收入或被退回的情形，分析研发样机的销售毛利率与同类产品的差异情况。

（二）核查结论

经核查，保荐人、申报会计师认为：

1、报告期内，公司销售人员和管理人员逐年增长，薪酬等级分布及构成情况合理，工作职责明确，奖金计提方式合理;销售费用与管理费用中职工薪酬增长的原因系随着公司经营规模扩大，销售人员和管理人员数量相应增加；职工薪酬水平与当地平均薪酬水平、同行业可比公司薪酬水平不存在重大差异，具有合理性；

2、报告期内公司研发人员数量、材料费用金额大幅增长具有合理原因，与在研项目、研发样机数量、取得的研发成果相匹配。研发人员专业、部门及岗位与研发工作相匹配；

3、兼职研发人员转为全职研发人员具有合理背景，公司制定了明确的标准对研发人员和生产人员予以区分，能够准确记录研发人员的工时以及在不同项目的投入情况，不存在研发人员与生产人员混同的情形；

4、公司研发样机相关会计处理符合《企业会计准则》和《监管规则适用指引——发行类第9号》规定。报告期内形成的研发样机在签署销售合同后，除一台客户尚在验证外，均已完成验收，不存在长期未结转收入的情形。研发样机的销售毛利率与同类产品的差异具有合理原因。
