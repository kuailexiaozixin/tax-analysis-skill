# 研发费用解读文章库 · 索引

> **本目录是什么**：研发产出物（试运行销售／样机、样品、副产品）会计与税务处理的**解读与反馈材料**存放处，共 5 份——4 篇公众号 HTML 原样留存的解读文章（A-01～A-03、A-05），加 1 篇作者本人向财政部办公厅提交的《企业会计准则——会计科目和主要账务处理（修订征求意见稿）》反馈意见（A-04，docx）。篇目集中在同一条主线上——会计准则解释第 15 号的规范结构、会计科目与账务处理落地、加计扣除中的费用冲减、研究阶段与开发阶段的划分标准，以及科目修订文本本身的衔接缺口。
> **证据力定位（引用前必读）**：本目录是**第三方解读层**，证据力**低于 `policy/` 与 `cases/`**。`policy/` 是法规与官方解读原文，`cases/` 是已定性的稽查处罚、项目鉴定、问询回复与判决；本目录只是作者对上述材料的梳理与评论，**不得当作明文条款引用，也不得作为结论依据**。结论落依据时仍回 `policy/` 条款或 `cases/` 编号；确需提及本目录的，只能标注为「第三方解读（非明文条款）」。
> **作者观点与条文的分界**：文中对政策意图、历史成因、修订用意的判断，以及针对其他文章误读所作的「纠正」，均属**作者观点**，不是官方文件；条文本身以 `policy/` 所存原文为准，引用前须回该目录核对现行效力。
> **A-04 的性质另需单独标注**：该件是**征求意见阶段的个人反馈意见**（立法建议），不是官方文件、不是条文、也不是案例。它援引的拟议稿条文可用来定位条款，但其中「应当修改为」「应予补充」等主张**尚无规则效力**；尤其「其他建议」中删去科目定义里「无形资产」定语的全套改写，只是建议稿。引用时标注「征求意见阶段个人反馈（非现行规定）」，不得据此认定现行账务处理应如何做。
> **文件形态**：A-01～A-03、A-05 为 HTML 原样保存，未转 md，四篇均无 `<title>`、无作者与发布日期元数据；正文图片多为 `mmbiz.qpic.cn` 外链，离线打开可能缺图，图题文字仍在。A-05 另无 h1–h4 标题标签，章节只能靠正文「一、」～「四、」序号识别，配 6 张自制示意图（图 1～图 6，题注在正文内）。A-04 为 docx 原样保存，未转文本，读取需 docx 解析；文中引号内多为拟议稿条文摘引，与作者主张在同一段落内交替出现，提取时须逐句区分归属。文件名的"深入解析""全新解读"等字样是原题，不作内容已核验的依据。
> **检索**：按文件定位查第一章，按篇内章节查第二章，按问题主题查第三章（主题—场景映射），引用与核验规则见第四章。
