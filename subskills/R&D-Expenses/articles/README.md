# 研发费用解读文章库 · 索引

> **本目录是什么**：研发产出物（试运行销售／样机、样品、副产品）会计与税务处理的**第三方解读文章**存放处，共 3 篇，均为公众号 HTML 原样留存。篇目集中在同一条主线上——会计准则解释第 15 号的规范结构、会计科目与账务处理落地、加计扣除中的费用冲减。
> **证据力定位（引用前必读）**：本目录是**第三方解读层**，证据力**低于 `policy/` 与 `cases/`**。`policy/` 是法规与官方解读原文，`cases/` 是已定性的稽查处罚、项目鉴定、问询回复与判决；本目录只是作者对上述材料的梳理与评论，**不得当作明文条款引用，也不得作为结论依据**。结论落依据时仍回 `policy/` 条款或 `cases/` 编号；确需提及本目录的，只能标注为「第三方解读（非明文条款）」。
> **作者观点与条文的分界**：文中对政策意图、历史成因、修订用意的判断，以及针对其他文章误读所作的「纠正」，均属**作者观点**，不是官方文件；条文本身以 `policy/` 所存原文为准，引用前须回该目录核对现行效力。
> **文件形态**：HTML 原样保存，未转 md。三篇均无 `<title>`、无作者与发布日期元数据；正文图片多为 `mmbiz.qpic.cn` 外链，离线打开可能缺图，图题文字仍在。文件名的"深入解析""全新解读"等字样是原题，不作内容已核验的依据。
> **检索**：按文件定位查第一章，按篇内章节查第二章，按问题主题查第三章（主题—场景映射），引用与核验规则见第四章。
> **核验**：2026-11-06 建索引。按目录实测 3 份 HTML；体量为实测字节数与去标签去空白后的字符数（含标点）；章节名取自篇内标题，第三篇自标"研发过程形成产品 · 系列（四）"，同系列其余篇目未收入本目录。

## 四、引用与核验规则

1. **只能作解读层引用**：出现在答复中时，标注为「第三方解读（非明文条款）」，不得写成"根据规定""依据 40 号公告第×条"——条文必须回 `policy/` 取原文并核现行效力。
2. **不得充当案例证据**：文中的案例叙述、11 个时点谱系、稽查镜鉴，都是作者的二次转述；结论需要案例支撑时，按 `cases/README.md` 定位原案并标明证据性质。
3. **不得以篇数代替强度**：三篇同源同主题，重复表述不构成相互印证。
4. **金额、比例、时点一律不取本目录**：文中示例数字（如 350 万元样机资金流向）为演示用假设，不得作为企业测算依据；比例与限额取 `policy/` 现行文件。
5. **作者观点须标注归属**：涉及政策意图、历史成因、"小瑕疵"、对他人解读的纠正，引用时写明"该文作者认为"，不与官方口径混述。
6. **改动提示**：篇内为公众号定稿，不含勘误；如发现与现行政策或 `policy/` 原文冲突，以 `policy/` 为准，并在本页核验记录中登记。
