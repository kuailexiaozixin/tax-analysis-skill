## 八、使用方法

1. 正查在第二章按编号或主体定位一行，同格读档、性质原语、事项码、文书号与底本行区间；反查按该章的档小节取整组案子，需要更细的性质时读档内"性质原语"列。
2. 只关心某一事项时读第三章，行内跨列即"同一事项、不同结论强度"的比较；需要该事项的全部案子按行取，需要某一结论下的事项分布按列取。
3. 引政策时读第四章，按角色列取用：监管原文与公司自行援引不可混引，作者延伸建议不得当作办案依据；行号回单案原文核对后再引。
4. 按风险／核查问题检索时读第七章，同时看"原句角色"与定位原句，不把检索标签引用为原文。
5. 案例集子案与专题的承载关系见第五章；编号空缺、移除记录、底本边界与待核引句见第六章，先读再引。
6. 全文检索按主体、完整文号、项目名称及定位原句进行；引用时回到该案来源及事实期间。
